4.智能体经典范式构造——ReAct

4.1 ReAct：推理（Reasoning）+ 行动（Acting）

4.1.1 ReAct 核心理念与运转机制

核心理念：让 AI 模型通过“一边想、一边做”的方式，多轮循环解决复杂问题。

核心运转机制：T-A-O 循环

  • Thought（思考）：分析当前情况、拆解任务、制定下一步计划，或反思上一步结果。
  • Action（行动）：执行具体动作，调用外部工具。
  • Observation（观察）：获取工具返回结果，基于结果再次进入思考环节。

让 AI 具备 ReAct 的五大关键要素

  1. 上下文（History）——Agent 的记忆
    维护对话历史，记录所有 T/A/O 过程，帮助模型参考过往经验，避免重复操作或陷入死胡同。

  2. 环境信息（Environment）——Agent 的感知
    当前时刻接收的信息（用户输入、系统状态等），作为推理输入条件，辅助决策下一步行动。

  3. 语言模型（LLM Thinking）——Agent 的大脑
    负责推理与决策。LLM 结合上下文（记忆）与环境信息（感知），生成执行计划，输出工具调用指令（ToolCall）。

  4. 工具（Tool）——Agent 的手脚
    执行具体功能的代码或接口，每个工具都有明确的输入与输出。

  5. 观察结果（Observation）——Agent 的反馈
    将工具返回结果存入历史记忆，作为下一轮推理的依据。

ReAct 的固有缺陷

  1. 强依赖底层 LLM 能力：推理能力弱、格式输出不规范，会直接导致任务失败。
  2. 效率低、成本高：多轮串行调用 LLM，耗时久、Token 消耗大。
  3. 提示词脆弱：模板稍有变动，稳定性大幅下降。
  4. 缺乏全局规划：易陷入局部最优，甚至出现死循环。

4.1.2 ReAct Agent 的编码实现流程

（1）系统提示词设计

定义 Agent 的角色、任务目标、思考规则、工具调用格式，规范 LLM 的输出逻辑。

（2）核心循环：while 循环

限制最大轮次（通常设 5 次，防止死循环），驱动 Agent 持续执行 思考 → 行动 循环：

  • 每一步重新生成提示词
  • 每一步调用大模型推理
  • 每一步执行对应动作

（3）输出解析器

将 LLM 的自然语言输出，转换为机器可识别的指令：

  • 示例：Thought（“我要查询北京今天天气”）→ Action（Weather[北京]）

（4）工具调用逻辑

解析动作指令，分支执行：

  • 若为 Finish[答案]：终止循环，返回最终结果
  • 若为 工具名[输入参数]：匹配对应工具并执行

（5）观测结果整合

将工具执行后的返回结果，存入历史上下文，作为下一轮思考的输入。

（6）运行实例

串联「提示词→循环→解析→工具→观测」全流程，完成一个可独立解决问题的 ReAct Agent。

class HelloAgentsLLM:
"""
大模型调用客户端
它用于调用任何兼容OpenAI接口的服务，并默认使用流式响应。
"""
def init(self, model: str = None, apiKey: str = None, baseUrl: str = None, timeout: int = None):
"""
初始化客户端。优先使用传入参数，如果未提供，则从环境变量加载。
"""
self.model = model or os.getenv("LLM_MODEL_ID") # 该参数后面还复用，存入类里
apiKey = apiKey or os.getenv("LLM_API_KEY")
baseUrl = baseUrl or os.getenv("LLM_BASE_URL")
timeout = timeout or int(os.getenv("LLM_TIMEOUT", 60)) # 60秒兜底值
# 检查三个必要参数是否有值
if not all([self.model, apiKey, baseUrl]):
raise ValueError("模型ID、API密钥和服务地址必须被提供或在.env文件中定义。")
# 创建一个大模型对象
self.client = OpenAI(api_key=apiKey, base_url=baseUrl, timeout=timeout)

def think(self, messages: List[Dict[str, str]], temperature: float = 0) -> str:
    """
    调用大语言模型进行思考，并返回其响应。
    """
    print(f"正在调用 {self.model} 模型...")
    try:
        response = self.client.chat.completions.create(
            model=self.model, 
            messages=messages,
            temperature=temperature,
            stream=True,
        )
        
        # 处理流式响应
        print("大语言模型响应成功:")
        collected_content = []
        # for循环持续等待接收数据流
        for chunk in response:
            if not chunk.choices:
                continue
            content = chunk.choices[0].delta.content or ""
            print(content, end="", flush=True)
            collected_content.append(content)
        print()  # 在流式输出结束后换行
        return "".join(collected_content) #传给后面的代码

    except Exception as e:
        print(f"调用LLM API时发生错误: {e}")
        return None

from typing import Dict, Any

class ToolExecutor:
"""
一个工具执行器，负责管理和执行工具。
"""
def init(self):
self.tools: Dict[str, Dict[str, Any]] = {}

def registerTool(self, name: str, description: str, func: callable):
    """
    向工具箱中注册一个新工具。
    """
    if name in self.tools:
        print(f"警告:工具 '{name}' 已存在，将被覆盖。")
        # 存入工具
    self.tools[name] = {"description": description, "func": func}
    print(f"工具 '{name}' 已注册。")

def getTool(self, name: str) -> callable:
    """
    根据名称获取一个工具的执行函数。
    """
    return self.tools.get(name, {}).get("func")

def getAvailableTools(self) -> str:
    """
    获取所有可用工具的格式化描述字符串。
    """
    return "\n".join([
        f"- {name}: {info['description']}" #列表推导式
        for name, info in self.tools.items() 
    ])

REACT_PROMPT_TEMPLATE = """
请注意，你是一个有能力调用外部工具的智能助手。

可用工具如下:
{tools}

请严格按照以下格式进行回应,不要添加任何多余符号(不要使用反引号、花括号或Markdown标记):

Thought: 你的思考过程
Action: 工具名称[工具输入]

例如：
Thought: 我需要搜索最新信息。
Action: Search[英伟达最新GPU型号]

当你收集到足够信息后，使用：
Thought: 我已经有答案了。
Action: Finish[最终答案]

现在，请开始解决以下问题:
Question: {question}
History: {history}
"""

class ReActAgent:
def init(self, llm_client: HelloAgentsLLM, tool_executor: ToolExecutor, max_steps: int = 5):
self.llm_client = llm_client
self.tool_executor = tool_executor
self.max_steps = max_steps
self.history = []

def run(self, question: str):
    """
    运行ReAct智能体来回答一个问题。
    """
    self.history = [] # 每次运行时重置历史记录
    current_step = 0

    while current_step < self.max_steps:
        current_step += 1
        print(f"--- 第 {current_step} 步 ---")

        # 1. 格式化提示词
        tools_desc = self.tool_executor.getAvailableTools()
        history_str = "\n".join(self.history) #拼接历史记录成字符串
        prompt = REACT_PROMPT_TEMPLATE.format(
            tools=tools_desc,
            question=question,
            history=history_str
        )

        # 2. 调用LLM进行思考
        messages = [{"role": "user", "content": prompt}]
        response_text = self.llm_client.think(messages=messages)
        
        if not response_text:
            print("错误:LLM未能返回有效响应。")
            break
        # 3. 解析LLM的输出，从大模型回答里抠出“思考”和“行动”
        thought, action = self._parse_output(response_text)
        
        if thought:
            print(f"思考: {thought}")

        if not action:
            print("警告:未能解析出有效的Action，流程终止。")
            break

        # 4. 执行Action
        if action.startswith("Finish"):
            # 如果是Finish指令，提取最终答案并结束
            final_answer = re.match(r"Finish\[(.*)\]", action).group(1)
            print(f"最终答案: {final_answer}")
            return final_answer
        
        tool_name, tool_input = self._parse_action(action)
        if not tool_name or not tool_input:
            # ... 处理无效Action格式 ...
            continue

        print(f"行动: {tool_name}[{tool_input}]")
        
        tool_function = self.tool_executor.getTool(tool_name)
        if not tool_function:
            observation = f"错误:未找到名为 '{tool_name}' 的工具。"
        else:
            observation = tool_function(tool_input) # 调用真实工具
        print(f"观察: {observation}")
        
        # 将本轮的Action和Observation添加到历史记录中
        self.history.append(f"Action: {action}")
        self.history.append(f"Observation: {observation}")

    # 循环结束
    print("已达到最大步数，流程终止。")
    return None

def _parse_output(self, text: str):
    """解析LLM的输出,提取Thought和Action。
    """
    # Thought: 匹配到 Action: 或文本末尾
    thought_match = re.search(r"Thought:\s*(.*?)(?=\nAction:|$)", text, re.DOTALL)
    # Action: 匹配到文本末尾
    action_match = re.search(r"Action:\s*(.*?)$", text, re.DOTALL)
    thought = thought_match.group(1).strip() if thought_match else None
    action = action_match.group(1).strip() if action_match else None
    return thought, action

def _parse_action(self, action_text: str):
    """解析Action字符串，提取工具名称和输入。
    """
    match = re.match(r"(\w+)\[(.*)\]", action_text, re.DOTALL)
    if match:
        return match.group(1), match.group(2)
    return None, None

if name == 'main':
# 1. 初始化大模型客户端（从 .env 读取配置）
llm_client = HelloAgentsLLM()

# 2. 初始化工具执行器并注册搜索工具
tool_executor = ToolExecutor()
search_description = "一个网页搜索引擎。当你需要回答关于时事、事实以及在你的知识库中找不到的信息时，应使用此工具。"
tool_executor.registerTool("Search", search_description, search)
'''继续新增工具可直接在下面接着写，例如

'''
# 3. 创建 ReAct 智能体
agent = ReActAgent(llm_client, tool_executor, max_steps=5)

# 4. 提出一个需要搜索才能回答的问题
question = "英伟达最新的GPU型号是什么？"
print(f"\开始运行 ReAct 智能体，问题：{question}\n")

# 5. 运行智能体

if final_answer:
    print(f"\n智能体最终回答：{final_answer}")
else:
    print("\n 智能体未能得出答案。")
